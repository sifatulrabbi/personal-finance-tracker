# Plan: Multi-Currency Support

## Context

The app currently hardcodes USD as the only currency. The user wants a multi-currency system where **BDT (Bangladeshi Taka)** is the base currency, with USD and EUR as additional supported currencies. All totals, balances, and trends are always in BDT. Transactions store both the original amount+currency and the BDT-converted amount. Exchange rates are household-configurable via a settings page.

---

## Key Design Decisions

1. **Account balances are always BDT.** No per-account currency. When a foreign-currency transaction hits an account, the BDT-converted amount updates the balance.

2. **Transactions store dual amounts.** Three new fields: `originalCurrencyCode`, `originalAmountMinor`, `exchangeRateToBdtMinor`. The existing `amountMinor` becomes the BDT amount. For BDT transactions, original = converted.

3. **Exchange rates stored as minor units.** "1 USD = 120.50 BDT" is stored as `rateToBdtMinor = 12050`. Conversion: `bdtMinor = Math.round(originalAmountMinor * rateToBdtMinor / 100)`.

4. **Rate snapshot per transaction.** Each transaction records the rate at creation time. Changing rates in settings only affects new transactions.

5. **BDT is always present and cannot be removed.** Its rate is always 100 (1.00).

## Step 3: Database Migrations

**New:** `src/libs/server/db/migrations/0014-create-currencies.sql`

```sql
CREATE TABLE currencies (
  id UUID PRIMARY KEY,
  household_id UUID NOT NULL REFERENCES households(id),
  code TEXT NOT NULL,
  symbol TEXT NOT NULL,
  name TEXT NOT NULL,
  rate_to_bdt_minor BIGINT NOT NULL,
  is_base BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (household_id, code),
  CHECK (rate_to_bdt_minor > 0)
);
```

**New:** `src/libs/server/db/migrations/0015-add-currency-to-transactions.sql`

- Add `original_currency_code TEXT NOT NULL DEFAULT 'BDT'`
- Add `original_amount_minor BIGINT NOT NULL DEFAULT 0`
- Add `exchange_rate_to_bdt_minor BIGINT NOT NULL DEFAULT 100`
- Backfill existing rows: `original_amount_minor = amount_minor`
